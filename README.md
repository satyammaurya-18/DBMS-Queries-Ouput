## <img src="https://img.icons8.com/color/48/about.png" width="25"> Overview

**DBMS Queries** is a comprehensive query-based learning and practice platform developed for students studying **Database Management Systems**.

The project contains a structured collection of **500 SQL and PL/SQL queries** based primarily on the standard **SCOTT schema**. It covers topics ranging from basic data retrieval and filtering to advanced database concepts such as subqueries, joins, cursors, procedures, triggers, packages, exception handling, and views.

This project can be used as a **digital DBMS practical file**, a learning resource, and a quick revision platform for SQL and PL/SQL concepts.

## <img src="https://img.icons8.com/color/48/download--v1.png" width="25"> Getting Started

### Clone the Repository

```bash
git clone https://github.com/satyammaurya-18/DBMS-Queries-Ouput.git
```

### Navigate to the Project Directory

```bash
cd DBMS-Queries-Ouput
```

### Run the Project

Since this is a frontend-based project, you can open:

```text
index.html
```

directly in your web browser.

### Using VS Code Live Server

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click inside the file.
4. Select **Open with Live Server**.

## <img src="https://img.icons8.com/color/48/learning.png" width="25"> Learning Coverage

The project follows a progressive learning approach:

```text
Basic SQL
    ↓
SELECT & WHERE
    ↓
LIKE & ORDER BY
    ↓
Group Functions
    ↓
JOINS
    ↓
SET Operations
    ↓
SUBQUERIES
    ↓
DDL / DML / DQL
    ↓
PL/SQL Blocks
    ↓
Cursors & Procedures
    ↓
Triggers & Packages
    ↓
Exception Handling & Views
```

This structure helps learners gradually move from fundamental database queries to more advanced SQL and PL/SQL concepts.
